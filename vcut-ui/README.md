# vcut-ui — หน้าตัดต่อแบบ OpenCut ที่ใช้ vcut_engine เป็นเครื่องยนต์

UI นี้เป็น "หน้ากาก" ของ [vcut_engine](../vcut_engine/) — ทุกการตัดสินใจและการ render
ยังเป็นของเอนจิน (edl.json + ffmpeg) เหมือนเดิม เบราว์เซอร์แค่แสดงผลและส่งคำสั่ง

## รัน

ต้องเปิด 2 ตัว:

```bash
# 1) เอนจิน (จากรากโปรเจกต์) — ผูกกับ 127.0.0.1:8765
./vcut view -c projects/phu-soi-dao.toml --no-open

# 2) หน้าเว็บ
cd vcut-ui && npm run dev        # เปิด http://localhost:3000
```

พอร์ตเอนจินเปลี่ยนได้ด้วย `VCUT_ENGINE_URL=http://127.0.0.1:xxxx npm run dev`
(ดู [next.config.ts](next.config.ts) — ทุกคำขอ `/engine/*` ถูก proxy ไปที่เอนจิน)

## เลเยอร์บนไทม์ไลน์ (แบบ OpenCut multi-track)

ไทม์ไลน์วาด 6 ชั้น (บน→ล่าง): **ข้อความขั้น 5** (เขียว) · **สติกเกอร์/ภาพซ้อน** (ชมพู) ·
**ซับอัตโนมัติ** (เทา อ่านอย่างเดียว) · **วิดีโอ** · **เสียงพูดในคลิป** (อ่านอย่างเดียว) ·
**เพลง** (ม่วง) — ปุ่มตาที่หัวแทร็กซ่อน/แสดงได้ทีละชั้น

- **ลากบล็อก** = เลื่อนเวลา · **ลากขอบขวา** = ยืดหด · **คลิก** = เปิดชิ้นนั้นในแผงซ้าย ·
  **ดับเบิลคลิก** = ลบ · บล็อกแดง = ชิ้นที่เกาะช่วงซึ่งถูกตัดออกไปแล้ว
- วางของใหม่ได้สองทาง: ปุ่ม &ldquo;ที่หัวเล่น&rdquo; ในแต่ละแท็บ หรือ**ลากจากแผงมาปล่อย**
  บนไทม์ไลน์ตรงจุดที่ต้องการ (เพลงจากคลัง · รูปจากคลัง · ข้อความใหม่ · ท่อนบทพูด)
- ข้อความ/สติกเกอร์ผูกกับ (คลิป, วินาทีในคลิป) ตามโมเดลของเอนจิน — สลับลำดับช็อตแล้ว
  ของพวกนี้ตามช็อตไปเอง ส่วนเพลงใช้เวลารวมของหนัง
- การแก้ทั้งหมดอยู่ในเบราว์เซอร์จนกด **บันทึก FX** (ปุ่มสีม่วงบน TopBar หรือในแผง) —
  เขียนกลับ fx.json ก้อนเดียว แล้วไปมีผลจริงตอน Export แบบมีเอฟเฟกต์
- **ยืดหดได้ทั้งสองขอบ** (ขอบซ้าย = เลื่อนจุดเริ่มโดยตรึงจุดจบ) รวมถึงแทร็กเพลงที่ตั้ง
  "เล่นจนจบ" (ยืดแล้วกลายเป็นความยาวชัดเจน)
- ข้อความ/สติกเกอร์**ซ้อนเวลากันได้สูงสุด 5 ชั้น** · เพลง/เสียงเอฟเฟกต์**ซ้อนได้ 6 ชั้น**
  (เอนจินวางแต่ละแทร็กด้วย adelay แล้ว amix รวมทีเดียว — ทับเวลากันได้จริงตอน render) —
  ชิ้นที่ทับกันแยกแถวให้อัตโนมัติ เกินเพดานแล้วระบบเตือนและไม่ให้เพิ่ม

## คีย์ลัด

| คีย์ | การทำงาน |
|---|---|
| `Space` | เล่น / หยุด |
| `Cmd/Ctrl+Z` | ย้อนกลับ (ครอบทั้งการตัดช็อตและเลเยอร์ · การพิมพ์/ลากติด ๆ กันนับเป็นก้าวเดียว) |
| `Cmd/Ctrl+Shift+Z` | ทำซ้ำ |
| `Cmd/Ctrl+S` | บันทึกทุกอย่างที่ค้าง (EDL + FX) |
| `-` / `=` | ซูมไทม์ไลน์ออก / เข้า — ยึดเส้นหัวเล่นสีแดงเป็นจุดหมุน (จุดที่กำลังดูไม่ไหลหนี) |
| `0` | ซูมพอดีหนังทั้งเรื่อง |
| `S` | ซอยช็อตตรงหัวเล่น |
| `Delete` | ลบบล็อกเลเยอร์ที่เลือกอยู่ (ถ้าไม่มีก็ลบช็อตที่เลือก) |

ปุ่มย้อนกลับ/ทำซ้ำอยู่ซ้ายสุดของแถบเครื่องมือไทม์ไลน์ และทุกปุ่มมี tooltip
บอกหน้าที่พร้อมคีย์ลัด (ชี้เมาส์ค้างไว้)

## Layout ขนาดหนัง

ปุ่มสัดส่วน (เช่น &ldquo;16:9 · 1920×1080&rdquo;) ใต้จอ preview เปิดเมนูขนาดยอดนิยม
13 แบบ 3 กลุ่ม: **แนวนอน** (YouTube FHD/4K/HD · Ultrawide 21:9 · Cinemascope
2.39:1 · คลาสสิก 4:3) · **แนวตั้ง** (TikTok/Reels/Shorts 9:16 · Instagram 4:5 ·
3:4 · Pinterest 2:3) · **จัตุรัส** (1:1) — เลือกแล้วเขียน `video.width/height`
ลงไฟล์โปรเจกต์ทันที (ขนาดกำหนดเองยังแก้ได้ในแท็บตั้งค่า)

- **จอ preview เปลี่ยนสัดส่วนตามทันที** — กรอบผืนหนังกลางเวทีปรับเป็นสัดส่วน
  ที่เลือก สตรีมเดิม (สัดส่วนเก่า) ถูกจัดวางในกรอบตามโหมด Fit/Fill/Stretch
  จนกว่าจะ Export ใหม่ และตัวอย่างซ้อนยึดกรอบใหม่ = ตำแหน่งจริงตอนเผา
- มีผลกับไฟล์จริงตอน Export — ขนาดฝังอยู่ในชื่อแคชของชิ้น ชิ้นที่ตัดไว้จึงถูก
  render ใหม่ให้เองโดยไม่ต้องสั่ง force
- คลิปที่สัดส่วนไม่ตรงผืน (คลิปนอนบนผืนตั้ง ฯลฯ) เลือกวิธีถมได้ 3 แบบใน
  ตั้งค่า → &ldquo;คลิปสัดส่วนไม่ตรงผืนทำยังไง&rdquo;: พื้นหลังเบลอ / แถบดำ /
  ครอปเต็มจอ — generalize ใน render.py ให้ใช้ได้ทุกสัดส่วนแล้ว (เดิมทำงานเฉพาะ
  คลิปตั้งบนผืนนอน)
- ตัวอย่างซ้อนสดสเกลข้อความตามความสูงผืนจริง (ass ใช้ PlayResY = ความสูง output)

## Preview ซ้อนสด

จอ preview วาด **ข้อความขั้น 5 + สติกเกอร์ + ซับอัตโนมัติ** ทับวิดีโอแบบเรียลไทม์
ด้วยตัวเลขชุดเดียวกับที่ ffmpeg จะเผาตอน render (x/y/ขนาด/สี/ขอบ/fade in-out
สเกลตามกรอบภาพจริง หัก letterbox ให้แล้ว) — ปุ่ม &ldquo;ซ้อน&rdquo; ใต้จอเปิด/ปิดได้

**เพลงประกอบดังตอนเล่นด้วย** — ทุกแทร็กใน fx เล่นซ้อนกับเสียงวิดีโอตามหัวเล่น
(at/dur, ความดังจาก gain_db, fade เข้า-ออก, loop) แก้ค่าในแผงเพลงแล้วได้ยินผล
ทันทีโดยไม่ต้อง render — สิ่งที่ยังไม่จำลอง: duck หลบเสียงพูด (ฟังของจริงตอน render)

สิ่งที่ยังไม่วาด: แผนที่เส้นทาง (journey) และรูปทรง — ดูของจริงตอน render ขั้น 5

## ทำอะไรได้แล้ว (แกนตัดต่อ)

- **ไทม์ไลน์จาก edl.json** — บล็อกช็อตพร้อมภาพ, สีแยกชนิด (น้ำเงิน = พูด, ม่วง = บรรยากาศ),
  แถบบท, ช็อตที่ยังไม่มีไฟล์ตัดขึ้นลายทแยงเหลือง
- **เล่นแบบไร้รอยต่อ** — ใช้สตรีม fMP4 สายเดียวของเอนจิน (`/api/live`) หัวเล่นวิ่งตรงกับไทม์ไลน์
  คลิกไม้บรรทัดเพื่อ seek (Space = เล่น/หยุด)
- **แก้ไทม์ไลน์** — ลากสลับลำดับ · ลบ (Delete) · ทำสำเนา · ซอยช็อตตรงหัวเล่น (S) ·
  trim ขอบ + เปลี่ยนชนิดในแผงขวา — ทั้งหมดอยู่ในเบราว์เซอร์จนกด **บันทึก EDL**
  ซึ่งยิง `POST /api/edl` (เอนจินตรวจทุกชิ้น + สำรอง edl.prev.json ให้เอง)
- **คลังคลิป** — คลิปทั้งหมดจาก manifest พร้อมป้ายว่าใช้ไปกี่ครั้ง กด + เพื่อเพิ่มต่อท้ายไทม์ไลน์
- **Export** — สั่ง render/assemble (หรือแบบมีข้อความ/เอฟเฟกต์) ผ่านคิวงานของเอนจิน
  มีการ์ดมุมจอโชว์ log สด แถบความคืบหน้า และปุ่มหยุด

## ขอบเขต (ตั้งใจ)

UI ไม่คำนวณอะไรเอง: ไม่ decode วิดีโอ, ไม่คิด loudness, ไม่เขียนไฟล์ — อ่าน/เขียนผ่าน
HTTP API ของ `serve.py` เท่านั้น ดังนั้นแก้ config, จัดบท, เพลง, caption ยังทำผ่าน
viewer เดิมหรือ CLI ได้ตามปกติ ข้อมูลชุดเดียวกัน
