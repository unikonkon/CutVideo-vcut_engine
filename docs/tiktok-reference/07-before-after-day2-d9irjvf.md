### ชั้นขั้น 5 — การ์ดชื่อคน + ป้ายค้างมุมจอ

การ์ดชื่อคนใต้ภาพ = `rrect` เป็นพื้น + `texts` ทับ:

```json
{
  "shapes": [{
    "kind": "rrect", "name": "<คลิปภาพ Dale Carnegie>", "at": 0.15, "dur": 1.5,
    "x": 0.5, "y": 0.72, "size": 340, "thick": 0.26,
    "color": "#000000", "border": 0.0,
    "behind": true, "anim": "fade", "in": 0.15, "out": 0.15
  }],
  "texts": [
    {"name": "<คลิปภาพ Dale Carnegie>", "at": 0.18, "dur": 1.45,
     "text": "Dale Carnegie", "x": 0.5, "y": 0.72,
     "size": 42, "color": "#FFFFFF", "border": 0.0,
     "anim": "fade", "in": 0.15, "out": 0.15},

    {"name": "<คลิปคนพูด>", "at": 0.0, "dur": 40.0,
     "text": "หนังสือ 3 เล่มที่ผมอยากให้ทุกคนอ่าน\nก่อนอายุ 30",
     "x": 0.22, "y": 0.12,
     "size": 26, "color": "#111111", "border": 0.0,
     "plate": true, "anim": "fade", "in": 0.3, "out": 0.3}
  ],
  "text": {
    "plate": {"color": "#FFFFFF", "alpha": 0.92, "pad": 12}
  }
}
```

> ป้ายค้างมุมซ้ายบนใช้ `plate` ไม่ใช่ `rrect` — เพราะกล่องต้อง**รัดตามความยาวข้อความ**
> ซึ่งเปลี่ยนทุกครั้งที่แก้ข้อความ · `rrect` เป็นแถบที่ต้องกำหนดขนาดเอง เหมาะกับการ์ดชื่อคน
> ที่อยากให้ทุกใบกว้างเท่ากันไม่ว่าชื่อจะยาวสั้นแค่ไหน
>
> `text.plate` เป็น**ค่ากลางตัวเดียวทั้งเรื่อง** ตั้งรายชิ้นไม่ได้โดยตั้งใจ — มันคือ "ลุค" ของหนัง

## 5 · สิ่งที่เห็นได้จากการเทียบ 06 กับ 07 เท่านั้น

สองคลิปนี้คือคนเดียวกัน ฟอร์แมตเดียวกัน ห่างกันหนึ่งวัน — **ตัวแปรเดียวที่ต่างคือฟุตเทจ**
และผลลัพธ์ต่างกันอย่างเป็นระบบ:

| | ฟุตเทจสัมภาษณ์ 2 คน (Day 1) | ฟุตเทจคนพูดคนเดียว (Day 2) |
|---|---|---|
| คัตต่อนาที | 32 | 22 |
| ช็อตเฉลี่ย | 1.92 วิ | 2.78 วิ |
| กระจุกคัตถี่ | มี 2 จุด | ไม่มี |
| B-roll ติดกัน | ได้ถึง 2 ชิ้น | ทีละ 1 ชิ้น |

**บทสรุปที่เอาไปตั้งค่าได้จริง:** `min_shot` กับ `run_max` ไม่ใช่ค่ารสนิยม
มันขึ้นกับว่าฟุตเทจมีคนพูดกี่คน ฟุตเทจสองคนต้องตัดถี่กว่าเพราะบทสลับหน้าเร็ว
ถ้าเอาสูตรของ Day 1 (`min_shot = 1.20`) ไปใช้กับฟุตเทจคนเดียว จะได้หนังที่ตัดถี่เกินเหตุ
โดยไม่มีบทโต้ตอบมารองรับ
