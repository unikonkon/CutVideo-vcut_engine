## 5 · แปลงเป็น vcut

### ค่าที่ตั้ง — สูตรนี้ต่างจากอีก 6 คลิปชัดเจน

```toml
[video]
width = 1080
height = 1920
vertical_mode = "blur_pad"

[jumpcut]
enabled     = true
noise_db    = -32.0
min_silence = 0.30
pad         = 0.08
min_piece   = 0.60

[talk]
margin_pre  = 0.20
margin_post = 0.35
gap_merge   = 0.60      # สูงกว่าสูตรอื่น — คลิปสอนไม่ควรตัดถี่
min_shot    = 2.00      # สูงกว่าสูตรอื่นเท่าตัว

[broll]
durations = [3.0, 2.0, 1.2]
run_max   = 2

[compose]
mode           = "pattern"
pattern        = ["TALK", "TALK", "BROLL"]   # เน้นเสียงพูด ไม่ใช่ภาพ
target_minutes = 1.9

[audio]
same_level  = true
master_lufs = -14.0
tp_ceiling  = -1.0
```

### แผนผังนีออน — ทำด้วย `shapes` + `texts` ของขั้น 5

ชิปหนึ่งอัน = `rrect` (พื้น) + `texts` (ตัวหนังสือ) วางทับ:

```json
{
  "shapes": [
    {"kind": "rrect", "name": "<คลิป>", "at": 0.0, "dur": 11.4,
     "x": 0.50, "y": 0.30, "size": 380, "thick": 0.30,
     "color": "#E0102A", "glow": 0.8, "behind": true, "anim": "pop", "in": 0.25},

    {"kind": "rrect", "name": "<คลิป>", "at": 1.8, "dur": 9.6,
     "x": 0.36, "y": 0.46, "size": 300, "thick": 0.30,
     "color": "#6E6E73", "behind": true, "anim": "pop", "in": 0.20},

    {"kind": "rrect", "name": "<คลิป>", "at": 2.6, "dur": 8.8,
     "x": 0.36, "y": 0.56, "size": 300, "thick": 0.30,
     "color": "#6E6E73", "behind": true, "anim": "pop", "in": 0.20}
  ],
  "texts": [
    {"name": "<คลิป>", "at": 0.05, "dur": 11.3, "x": 0.50, "y": 0.30,
     "text": "Content/Script", "size": 46, "color": "#FFFFFF",
     "border": 0.0, "anim": "pop", "in": 0.25},
    {"name": "<คลิป>", "at": 1.85, "dur": 9.5, "x": 0.36, "y": 0.46,
     "text": "Viewer's goal", "size": 36, "color": "#FFFFFF",
     "border": 0.0, "anim": "pop", "in": 0.20}
  ]
}
```

> ทั้ง `shapes` และ `texts` ผูกเวลากับ **(คลิป, วินาทีในคลิป)** ไม่ใช่วินาทีในหนัง
> ลากสลับลำดับช็อตในไทม์ไลน์ได้โดยชิปทั้งผังไม่หลุดตำแหน่ง

`glow` (0–1) ทำให้ชิปเรืองแสงแบบเดียวกับต้นฉบับ — ชิปหลักสีแดงเปิดไว้ ส่วนหัวข้อย่อย
สีเทาปล่อยเป็น 0 ก็ได้ความต่าง "เรืองแสง = หัวข้อหลัก" ตรงกับที่คลิปนี้ทำ

### เส้นเชื่อมนีออน — `journey` โหมด `neon`

```json
{"journey": {
  "enabled": true, "look": "neon", "glow": 0.9,
  "line": "#FFFFFF", "trail": "#2A3B4A", "core": "#FFFFFF",
  "panel": 0.0, "figure": 8, "show_dist": false,
  "d": "M 60 460 C 240 430 300 200 480 210 L 900 110",
  "stops": [{"label": "Content/Script", "name": "<คลิป>", "at": 0.4}]
}}
```

เส้นถูกวาดสามชั้น (ฮาโลกว้าง · ฮาโลแคบ · แกนขาว) ด้วย `\bord` + `\blur` ของ libass
— ช่วงที่ "เดินผ่านแล้ว" สว่างเต็ม ส่วนช่วงที่ยังไปไม่ถึงหรี่ลงครึ่งหนึ่ง ซึ่งตรงกับ
ที่ต้นฉบับทำ (เส้นทยอยสว่างขึ้นตามที่เล่าถึง)

> `panel = 0` ปิดพื้นหลังแผง · `figure` เล็ก ๆ ทำให้ตัวคนเดินแทบมองไม่เห็น —
> ตัวชั้นนี้ชื่อ "แผนที่เส้นทาง" แต่สิ่งที่มันวาดจริงคือ **เส้นโค้งที่ทยอยสว่าง
> พร้อมหมุดกับป้าย** ซึ่งเป็นของเดียวกับผังนีออนพอดี

### ที่ vcut ทำเองไม่ได้

| ของ | ทางออก |
|---|---|
| สคริปต์เลื่อนขึ้น | **ยังไม่มีในเอนจิน** — ทำเป็นคลิปวิดีโอแยกแล้วใส่เป็นช็อต |
| ป้ายชื่อจุดเป็นตัวหนังสือละติน | `journey` ใช้ฟอนต์ตัวเดียวทั้งชั้น — ตั้ง `journey.font` แยกจากสไตล์ซับได้ |

ทำได้แล้วสามอย่างที่เอกสารรุ่นแรกบอกว่าทำไม่ได้:

| ของ | ทำด้วย |
|---|---|
| **เส้นนีออนโค้งเรืองแสง** | `journey.look = "neon"` + `glow` — วาดเส้นโค้งพร้อมแสงฟุ้งสามชั้น |
| **ชิปเรืองแสง** | `shapes[].glow` — ตัววาดตัวเดียวกับเส้น ชิปกับเส้นจึงเป็นชุดเดียวกัน |
| **กล้องเคลื่อนตามเส้น** | `clips[].zoom_to` + `pan` — ซูมเดินตามเวลาแทนที่จะค้าง |

## 6 · บทเรียนที่เอาไปใช้กับคลิปอื่นได้

ครึ่งหลังของคลิปนี้พิสูจน์ว่า **"ภาพไม่นิ่ง" ไม่จำเป็นต้องมาจากการตัด** 51 วินาทีที่มีคัตแค่ 2 จุด
ยังดูไม่น่าเบื่อ เพราะมีของใหม่โผล่บนจอตลอดเวลา

ในภาษาของ vcut แปลว่า: ช็อตยาว ๆ ที่กลัวว่าจะน่าเบื่อ แก้ด้วยการ**ทยอยวาง `shapes`/`texts`
เหลื่อม `at` กัน**บนช็อตเดียว ได้ผลดีกว่าการซอยช็อตให้สั้นลง — และไม่ต้อง render ใหม่ด้วย
เพราะขั้น 5 ไม่แตะไทม์ไลน์ของขั้น 3
