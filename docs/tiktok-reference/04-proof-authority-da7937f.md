### ชั้นขั้น 5 — ช็อตหลักฐานต้องยาว

กันไม่ให้ `[jumpcut]` ซอยช็อตที่มีตัวเลขให้อ่าน โดยชะลอความเร็วแทนการต่อคลิปให้ยาว:

```json
{
  "clips": {
    "<คลิปแดชบอร์ด>@19.100+11.230": {"speed": 0.9, "zoom": 1.08, "grade": "punch"},
    "<คลิปยิงรัว>@30.330+0.600": {"zoom": 1.12},
    "<คลิปยิงรัว>@30.930+0.500": {"zoom": 1.18},
    "<คลิปยิงรัว>@31.430+0.540": {"zoom": 1.24}
  },
  "shapes": [{
    "kind": "rrect", "name": "<คลิปแดชบอร์ด>", "at": 1.2, "dur": 3.0,
    "x": 0.5, "y": 0.30, "size": 420, "thick": 0.34,
    "color": "#E0102A", "behind": true, "anim": "pop"
  }]
}
```

> `behind: true` จำเป็น — `rrect` คือ**พื้นหลังของชิปตัวเลข** ถ้าไม่ตั้ง มันจะวาดทับตัวเลข
> ที่มันมีไว้รองพอดี แล้วตัวเลขหายสนิทโดยไม่มีอะไรฟ้อง
