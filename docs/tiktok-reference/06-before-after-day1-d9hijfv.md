## 4 · แปลงเป็น vcut

### ค่าที่ตั้ง — สูตรนี้ตรงกับ vcut มากที่สุดในทั้งเจ็ดคลิป

```toml
[video]
width = 1080
height = 1920
vertical_mode = "crop"       # ฟุตเทจสัมภาษณ์เป็นแนวนอน ต้องครอปเป็น 9:16

[listen]
enabled = true               # ต้องเปิด — B-roll ถูกวางตามคำพูด
language = "th"

[jumpcut]
enabled     = true
noise_db    = -32.0
min_silence = 0.28
pad         = 0.06
min_piece   = 0.45

[talk]
margin_pre  = 0.15
margin_post = 0.25
gap_merge   = 0.40
min_shot    = 1.20           # ตรงกับช็อตเฉลี่ย 1.92 วิ ของช่อง After

[broll]
durations = [2.0, 1.5, 1.0]
run_max   = 2
pick      = "center"

[compose]
mode           = "pattern"
pattern        = ["TALK", "TALK", "BROLL"]   # B-roll แทรกทุก ~3 ช็อต ตามที่วัดได้
target_minutes = 1.0

[audio]
same_level  = true
master_lufs = -14.0

[encode]
bitrate = "12M"
maxrate = "16M"
bufsize = "32M"
```

### เลย์เอาต์ทั้งใบ — `vcut compare` (ขั้นที่ 6)

เรขาคณิตที่วัดจากคลิปนี้กลายเป็นเลย์เอาต์ `tilt` ของเอนจินแล้ว:

```bash
./vcut compare --set compare.enabled=true \
  --set compare.before=IMG_1234.mp4 \
  --set compare.title="ฝึกตัดในมือถือ" --set compare.subtitle="Day 1/100" \
  --set compare.timeline=capcut-screenrec.mp4      # ไม่มีก็ปล่อยว่าง
```

ฝั่ง After คือไฟล์ล่าสุดที่ทำไว้ (ขั้น 5 → 4 → 3) · ฝั่ง Before คือฟุตเทจดิบ ·
**ฝั่งที่จบก่อนค้างเฟรมสุดท้ายรออีกฝั่ง** ซึ่งคือสิ่งที่ทำให้เห็นว่า After สั้นกว่า

### ที่ vcut ทำเองไม่ได้

| ของ | ทางออก |
|---|---|
| ภาพวงกลมมุมขวาบน | ครอปเป็น `.png` วงกลมพื้นโปร่งไว้ก่อน → `overlays` |
| แถบไทม์ไลน์ CapCut ด้านล่าง | เป็นสกรีนเรคคอร์ดของแอปจริง — อัดหน้าจอมาแล้วใส่ `compare.timeline` ได้ แต่เอนจินไม่ได้จำลองแถบขึ้นมาเอง |

## 5 · วิธีใช้เอกสารนี้จริง

คลิปนี้ตอบคำถาม **"หนังที่ vcut ตัดออกมา ควรมีหน้าตายังไงถึงจะถือว่าดี"** ได้ตรงที่สุด
เพราะช่อง After คือเป้าหมาย และช่อง Before คือของที่ป้อนเข้าไป

ค่าที่ควรลอกไปใช้ก่อน: `min_shot = 1.20` · `pattern = ["TALK","TALK","BROLL"]` · `run_max = 2`
สามค่านี้มาจากการวัดช่อง After ตรง ๆ ไม่ได้เดา
