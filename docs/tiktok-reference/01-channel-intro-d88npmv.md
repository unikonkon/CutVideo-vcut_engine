## 5 · แปลงเป็น vcut

### ที่ใช้ได้ทันที

```toml
[video]
width = 1080
height = 1920
vertical_mode = "blur_pad"

[jumpcut]                    # ต้นฉบับไม่มีเงียบเลย = ตัดชิดสุด
enabled     = true
noise_db    = -32.0
min_silence = 0.25
pad         = 0.05
min_piece   = 0.40

[talk]
margin_pre  = 0.12
margin_post = 0.20
gap_merge   = 0.35
min_shot    = 0.80           # ต่ำกว่าปกติ เพื่อให้ได้ชุดตัดถี่ช่วงกลาง

[broll]
durations = [1.5, 1.0, 0.6]  # ช่วงยิงตัวอย่างรัว
run_max   = 7                # ต้นฉบับปล่อยติดกัน 7 ชิ้น

[compose]
mode           = "pattern"
pattern        = ["TALK", "BROLL"]
target_minutes = 0.55

[audio]
same_level  = true
master_lufs = -14.0          # ไม่แนะนำให้ไล่ถึง −9.8 (ดูข้อ 6)

[encode]
bitrate = "12M"
maxrate = "16M"
bufsize = "32M"
```

### ที่ vcut ทำเองไม่ได้ — ต้องเตรียมไฟล์เอง

| ของ | ทางออก |
|---|---|
| มาสคอต 3D พื้นโปร่ง | เรนเดอร์เป็น **ProRes 4444 (.mov)** ช่องอัลฟา แล้ววางเป็น `overlays` — ทดสอบแล้วว่าพื้นทะลุถึงจริง (`.webm` อัลฟาใช้ไม่ได้กับ ffmpeg ในเครื่องนี้) |
| พื้นกระดาษยับแดง | ทำเป็นภาพนิ่ง 1080×1920 แล้ววางเป็นคลิปพื้นหลัง |
| glitch / RGB แยกช่อง | **ทำได้แล้ว** — `clips[].glitch` (0–1) + `glitch_hz` · แยกช่องสีจริงด้วย `rgbashift` ไม่ใช่ overlay สำเร็จรูป |
| ตัวหนังสือเด้งทีละคำ | **ทำได้แล้ว** — `anim` = `pop_words` / `fade_words` · แทรกแท็กกลางบรรทัด ให้ libass จัดวางเอง ไม่ต้องแยกเป็นหลายชิ้น |

## 6 · ข้อควรระวัง

ต้นฉบับ −9.8 LUFS **อย่าไล่ตาม** — TikTok ปรับความดังขาเข้าที่ประมาณ −14 LUFS อยู่แล้ว ส่งไฟล์ที่ดังกว่านั้นไม่ได้ทำให้ดังขึ้นบนแอป ได้แค่โดนกดกลับลงมาพร้อมกับไดนามิกที่เสียไปถาวร ตั้ง `master_lufs = -14.0` แล้วปล่อยให้แพลตฟอร์มทำงานของมัน
