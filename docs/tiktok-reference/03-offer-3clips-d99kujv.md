### ชั้นขั้น 5 — เลขที่นับถอยหลัง

"เปิดรับอีกแค่ 2 ท่าน" → "1 ท่าน" ทำด้วยการ์ดสามบรรทัดสองชิ้น
เปลี่ยนแค่บรรทัดกลาง บรรทัดบน-ล่างเหมือนกันเป๊ะ ตำแหน่งจึงไม่ขยับ:

```json
{
  "texts": [
    {
      "name": "<คลิป>", "at": 0.0, "dur": 4.37,
      "x": 0.5, "y": 0.42, "anim": "fade", "in": 0.20, "out": 0.12,
      "lines": [
        {"text": "เปิดรับอีกแค่", "size": 72, "color": "#FFFFFF",
         "outline": "#000000", "border": 5.0, "bold": true},
        {"text": "2", "size": 190, "color": "#FFFFFF", "gap": 0.10, "bold": true},
        {"text": "ท่าน", "size": 72, "color": "#FFFFFF", "gap": 0.05}
      ]
    },
    {
      "name": "<คลิปถัดไป>", "at": 0.0, "dur": 4.47,
      "x": 0.5, "y": 0.42, "anim": "none",
      "lines": [
        {"text": "เปิดรับอีกแค่", "size": 72, "color": "#FFFFFF",
         "outline": "#000000", "border": 5.0, "bold": true},
        {"text": "1", "size": 190, "color": "#FFFFFF", "gap": 0.10, "bold": true},
        {"text": "ท่าน", "size": 72, "color": "#FFFFFF", "gap": 0.05}

```

> ชิ้นที่สองตั้ง `anim: "none"` โดยตั้งใจ — ถ้าเฟดเข้าใหม่ทั้งการ์ด สายตาจะอ่านว่า
> "การ์ดใหม่" แทนที่จะเป็น "เลขลดลง" ซึ่งทำลายผลของการนับถอยหลังทั้งหมด

### ที่ vcut ทำเองไม่ได้

| ของ | ทางออก |
|---|---|
| glitch ขาวดำ 2 วิ | **ทำได้แล้ว** — `clips[].glitch` + `grade` = `bw` บนช็อตนั้นทั้งช็อต ไม่ต้องเตรียมคลิปแยก |
| สกรีนช็อตซูมเข้า | **ทำได้แล้ว** — `zoom` → `zoom_to` ไล่ตามเวลา + `pan` เลือกทิศที่กรอบภาพไถลไป |
| มีม/ภาพนิ่ง | วางเป็น `overlays` ตั้ง `width` เป็นสัดส่วนจอ |
